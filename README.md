Entry for the [make.fun bounty "One Star, Written in Sap"](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
($2 total prize pool, top 5 paid, 1st place $0.73). The bounty asks for one
line, under 280 characters, written as a one-star review by a houseplant of
the human who owns it — a grievance and a reason for the single star, funny
enough to win a pairwise judge.

## The entry

```text
One star. My human waters me when he remembers, which is never, then blames the sun for my feelings. I photosynthesize out of spite now.
```

136 characters, one line.

## How it works

Run `python3 main.py` and it writes the review above, byte for byte, to
`/output/entry.txt`, then reads the file back to confirm it matches the
draft. Nothing else is written, and the program never reads anything else:
the same bytes come out on every run.

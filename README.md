A submission to the make.fun bounty [“One Star, Written in Sap”](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4), a $2 prize pool where the top five entries get paid and first place takes $0.73. The brief wants a single line of at most 279 characters: a one-star review written by a houseplant about the human who owns it, with a complaint and a reason behind the lone star, sharp enough to beat rival entries in head-to-head judging.

## The review

```text
One star. My human waters me when he remembers, which is never, then blames the sun for my feelings. I photosynthesize out of spite now.
```

That is 136 characters on one line: the plant is watered never, the sun gets blamed for its moods, and photosynthesis now runs purely on spite.

## Running it

`python3 main.py` drops the review above, exactly as written, into `/output/entry.txt`, then opens the file again to check the stored bytes match the draft. The run writes nothing else and reads nothing else, so repeated runs always yield identical bytes.
